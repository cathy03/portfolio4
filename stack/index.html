다양한 프로덕트 간 일관성 없는 UX/UI와 컴포넌트 중복 사용으로 인해 브랜드 경험 분산,개발 리소스 비효율로 인한 빠른 성장의 제약 발생
모든 프로덕트가 공통된 UX 원칙과 UI 패턴을 따르도록 디자인 시스템을 표준화하여 사용자 경험의 일관성을 높이고 브랜드 신뢰도 제고
Foundation, Component, Token 기반의 Core Design System을 구축해 디자이너와 개발자가 빠르게 실험하고 확장 가능한 환경 마련
다양한 프로덕트 간 일관성있는
경험을 위한 토큰 구조 설계
일반적인 디자인 시스템의 토큰 구조와 다르게 Brand Theme을 추가하여, 프로덕트 확장성을 열어두면서 컴포넌트의 UX/UI 통일성을 유지하도록 하였습니다.
Core System 구축에 집중하여,
디자인 시스템 기반 마련
디자인 시스템 기본 구조를 마련하고, Pattern과 Template 각 프로덕트 시스템에 만들어 놓습니다. 각 프로덕트 시스템의 사용 빈도가 높아지는 요소는 Core System으로 옮겨 놓는 프로세스를 통해 UX일관성을 유지하도록 구축하였습니다.
AI를 이용하여 시스템 구축 리소스 절약 및
일관성있는 코드 구조 실험
컴포넌트 별 디자인 및 개발자가 달라짐으로 인해 기존 코드를 파악하고, 컨벤션을 이해하는 데 시간이 걸리는 문제가 발생하였습니다. 그래서 AI 템플릿을 만드는 실험을 진행하였습니다. 새로운 작업자가 빠르게 컨텍스트를 이해하고 작업할 수 있도록 가이드 역할을 하는 도구로, 디자인과 개발 요청 문서를 토대로 PRD와 템플릿 코드를 생성해주었고, 실제로 초기 개발에 드는 시간을 대폭 줄여주었습니다.
